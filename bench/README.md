# Selected benchmark helpers

This directory retains client/auth helpers (`harness.py`), smoke tools (`api_smoke.py`), and realistic prompts (`prompts_real.jsonl`). It does not provide the complete current campaign harness. Selected v0.32 evidence directories retain frozen driver and evaluation-input snapshots for their recorded runs; those snapshots are evidence, not a unified runnable benchmark distribution.

Use the [methodology](../docs/methodology.md) and [campaign reports](../docs/campaigns/README.md) for protocols and actual measurement boundaries. See the [evidence policy](../docs/evidence-policy.md) for dataset/export scope.
