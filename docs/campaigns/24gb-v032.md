# 24 GB Blackwell: Qwen3.8-27B benchmark dossiers

Scope: Qwen3.8-27B on the NVIDIA RTX PRO 4000 Blackwell SFF (24 GB, SM120, 70 W), using vLLM 0.32.0 and FlashInfer 0.7.0.post1 with one active request. Weight precision, KV precision, drafting method, and cache mode are stated for each comparison.

PP is prompt-processing throughput; TG tables distinguish complete-request output throughput from decode rate. Context admission, physical KV pool capacity, and actually occupied context are separate quantities. The standing GSM8K gate is 190/200. See [methodology](../methodology.md) for the evaluation regimen and sampling profiles.
